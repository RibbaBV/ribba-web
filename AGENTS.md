## CodeRabbit vóór samenvoegen

Wacht na elke push naar een PR ongeveer tien minuten zodat CodeRabbit de laatste commit kan beoordelen. Controleer daarna de review, inline opmerkingen en onopgeloste discussies. Verwerk geldige bevindingen en leg bij andere bevindingen uit waarom een wijziging niet nodig is. Iedere nieuwe push start de wachttijd opnieuw. Voeg de PR pas samen als de bevindingen zijn afgehandeld en de vereiste checks op diezelfde commit geslaagd zijn.
